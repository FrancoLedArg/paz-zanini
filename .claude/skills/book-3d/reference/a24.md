# A24 CD site: what it does

Reverse-engineered from the bundles of https://a24.raviklaassens.com/ on 2026-11-16 (read, not run). Values are their tuning for a CD; treat them as starting points for books, not answers.

## Stack

Vanilla three.js r178, GSAP + ScrollTrigger + CustomEase, Lenis smooth scroll (`lerp: coarse ? 1 : 0.165`, so native on touch), Barba page transitions. No R3F, no drei, no postprocessing, no shadow maps, no .glb or .hdr files.

## Renderer

`antialias: true`, `alpha: true`, `powerPreference: "high-performance"`, `ACESFilmicToneMapping`, `toneMappingExposure: 0.86`, `SRGBColorSpace`, `transmissionResolutionScale: 0.5`, textures at `renderer.capabilities.getMaxAnisotropy()`.

## Environment

A 1024×512 canvas painted as a vertical gradient `#25282f` → `#0e0f13` → `#020203`, with four soft white horizontal bands at different heights and strengths. Mapped as `EquirectangularReflectionMapping`, passed through `PMREMGenerator.fromEquirectangular`, used as the environment. The bands are the streaks seen in reflections.

## Lights

Ambient 0.25; warm key `#FFF9E8` at 0.75 from below; fill 0.3; blue rim `#499FF5` at 0.75 from behind; `RectAreaLight` strip 6 × 0.4 at intensity 1.9 above the subject; `Fog("#FFFFFF", 7, 14)`.

## Materials (all MeshPhysicalMaterial)

| Part | Values |
|---|---|
| Label face | `metalness 0.48, roughness 0.42, clearcoat 0.8`, normal + roughness maps |
| Data side | `metalness 1, roughness 0.23, iridescence 1, iridescenceIOR 1.86, iridescenceThicknessRange [140, 900]`, radial normal map |
| Rim | `roughness 0.04, clearcoat 0.7, envMapIntensity 1.8` |
| Hub | `transmission 0.68, ior 2, thickness 0.6` |

## Procedural micro-detail (the key technique)

A Blob Web Worker builds height maps and converts them to normal maps by central differences. Front: value-noise "ink" grain, ~30 random line scratches, ~500 dust specks. Roughness: grain noise plus concentric gloss rings. Back: radial ring normals. Normal maps 1024 px, roughness 512 px, cached.

## Geometry

`LatheGeometry` with a bevelled profile at 256 segments; `RingGeometry` faces at 220 segments. The only loaded asset is the cover art (`disc.webp`), drawn to a canvas with an annulus clip and a brightness/contrast/saturate filter.

## Motion

Spring snapping (`frequency 9.5, damping 12`), drag with friction 0.89, hover tilt 0.21 rad, idle spin, gallery tilted −30°/−30°, staggered fly-in with a pop scale, scroll-driven push and spin.

## Performance

`dpr = min(devicePixelRatio, width <= 767 ? 1.5 : 2)` plus a pixel budget (12e6 gallery; 2.6e6 with max ratio 1.5 for the hero). Adaptive tiers `[1, 0.85, 0.7, 0.55]` step down when average frame time exceeds 26.5 ms. Shaders precompiled (`compileAsync`, `initTexture`), a spare renderer prewarmed in `requestIdleCallback`, only discs within a radius of 5 rendered, WebGL context loss handled, `prefers-reduced-motion` branches.

## Translation to books

| CD | Book |
|---|---|
| Label face: clearcoat over grain | Cover laminate over the Tapa |
| Bright polished rim | Bevel on board edges |
| Radial ring normals | Fine lines along the page block |
| Scratches and dust | Same, fainter, on the laminate |
| Softbox bands in the environment | Same; tune for the cover highlight |
| Blue rim light | Cool rim separating the book from the page |
